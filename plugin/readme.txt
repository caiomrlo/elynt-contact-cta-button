== Description ==

Transform your website traffic into direct sales and leads with the **Elynt Contact CTA Button**. This lightweight and professional WordPress plugin enables you to add beautiful, high-converting WhatsApp chat buttons and floating call-to-action (CTA) widgets in seconds. 

Whether you want a global floating WhatsApp button or an inline chat box embedded in your blog posts, this plugin gives you complete control over your customer communication channels.

= 🚀 Optimized for Conversions & Sales =
With instant access to WhatsApp, you reduce friction for prospective customers, boosting conversion rates and driving more leads directly to your phone number.

= 🎨 Fully Customizable =
This plugin allows you to easily change the appearance of the button by customizing the color, size, etc.

### Key Features:
*   **Two Layout Types:** Choose between **Standard (Icon + Text)** to encourage clicks, or **Round (Icon Only)** for a minimalist design.
*   **Flexible Placements:** Display buttons as **Fixed/Floating** widgets in the bottom-left or bottom-right, or place them as **Inline** elements anywhere using shortcodes.
*   **Advanced Display Targeting:** Show buttons globally, or restrict them to specific pages, entire post types, or select posts manually using autocomplete search targeting.
*   **Pre-filled Initial Messages:** Set custom default messages so users can start conversations with predefined text (e.g., "Hello, I would like more information about your services!").
*   **Custom Styling & Branding:** Change background colors, text colors, icon size (px), and font size (px) to perfectly fit your theme.

== Frequently Asked Questions ==

= How do I add a WhatsApp button to a specific page or post? =
You can easily display buttons in two ways:
1. **Auto-Placed (Fixed/Floating):** Set the display targeting to show the button globally or on specific post types/custom posts. The plugin handles the placement automatically.
2. **Inline (Shortcode):** Set the button type to Inline, copy the provided shortcode (e.g., `[elyncoct_chat_button id="X"]`), and paste it anywhere in your page builder, block editor, or classic editor content.

= Can I customize the style of the WhatsApp buttons? =
Yes! You can customize the button layout (Standard or Round), fixed screen position (Bottom Left or Bottom Right), background color, text color, icon size (in pixels), and font size (in pixels) for every button you create.

= Can I pre-populate a message for users starting a chat? =
Absolutely. You can define a unique "Initial Message" for each button. When a visitor clicks the button, WhatsApp will open with this message already typed out, making it easier for them to hit send.

= Does this plugin support custom display targeting? =
Yes! In version 1.2.0, we introduced custom display targeting. You can configure buttons to only appear on specific post types (like Posts or Pages) or manually select target posts/pages using our autocomplete search field.

= Will this plugin slow down my website? =
No. Elynt Contact CTA Button is optimized for speed. It uses custom database tables and loads minimal, highly-optimized CSS/JS files only when needed, keeping your site fast and SEO-friendly.
