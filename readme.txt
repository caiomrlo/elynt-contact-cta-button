A clean and powerful plugin to create WhatsApp Call-to-Action buttons with a modern SPA-like admin interface.

== Description ==

Elynt Contact CTA Button is a professional WordPress plugin designed to help you connect with your customers via WhatsApp. With a focus on performance and user experience, it allows you to create beautiful, conversion-optimized WhatsApp CTA buttons in seconds.

**Key Features:**

*   **Modern Admin UI:** Fast, SPA-like dashboard for managing your buttons without page reloads.
*   **Highly Customizable:** Easily configure button text, WhatsApp number, and predefined initial messages.
*   **Two Display Modes:** Choose between Fixed (floating) buttons for global reach and Inline (shortcode) buttons for specific content placement.
*   **Lightweight & Fast:** Optimized code and custom database tables to ensure zero impact on site performance.
*   **Premium Aesthetics:** SaaS-inspired admin panel and recognizable, conversion-focused WhatsApp frontend styles.

== Frequently Asked Questions ==

= How do I add a button to a specific page? =
For Inline buttons, the plugin provides a shortcode that you can copy and paste anywhere in your content.

= Can I have multiple buttons? =
Yes! You can create and manage multiple buttons from the centralized dashboard.
